# AI Companion

A local voice companion built with Python. It listens through your microphone, replies with a local language model (Ollama), and speaks the reply with Chatterbox text-to-speech.

## Status
Personal, non-commercial fan project.

## Requirements
- Windows, Python 3.12, and an NVIDIA GPU (recommended)
- Ollama with the model named in `config.py`
- Internet connection for Google speech recognition

## Notes
- Voice reference clips are not included. If you use one, you must have permission from the voice's owner.
- The character Ganyu is from Genshin Impact, owned by HoYoverse. This project is not affiliated with them.
